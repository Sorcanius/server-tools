# bootstrap

Werkzeuge zur Installation und Verwaltung des server-tools-Frameworks selbst.

- `manage-server-tools.sh`: Installation, harter Sync und Status
- `setup-server-tools-sync.sh`: regelmäßigen GitHub-Sync per Cron einrichten
- `setup-mqtt-env.sh`: globale MQTT-Credential-Datei unter `/etc/mqtt.env` anlegen

Lokale Konfigurationen werden nicht in diesem Verzeichnis gespeichert.
